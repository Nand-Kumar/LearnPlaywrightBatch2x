# Visual Studio Code Keyboard Shortcuts for macOS

### Key Symbols Legend

- `⌘` : Command (Cmd)
- `⇧` : Shift
- `⌥` : Option (Alt)
- `⌃` : Control (Ctrl)
- `⇪` : Caps Lock
- `⌫` : Delete (Backspace)
- `⏎` : Return (Enter)

---

## 1. General

| Shortcut    | Action                    |
| :---------- | :------------------------ |
| `⇧⌘P`, `F1` | Show Command Palette      |
