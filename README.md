# Learn Playwright Batch 2x

A structured learning repository covering JavaScript fundamentals and test automation concepts for **Playwright Batch 2x**.

---

## 📂 Repository Structure

```text
LearnPlaywrightBatch2x/
├── chapter_01_Basics/
│   ├── 01_Basics.js                           # Getting started with JavaScript
│   ├── 02_JS.js                               # Core JavaScript syntax
│   ├── 03_JS_Commands.js                      # Basic JS commands & console outputs
│   └── 04_Hotcode_ex.js                       # Hot code execution examples
│
├── Chatper_02_Javascript_Concepts/
│   └── 05_JS_Basics.js                        # Core JavaScript concepts
│
└── Chapter_03_Identifier_Literals/
    ├── 06_Identifier_Rules.js                 # Identifier rules, naming cases & real-world use cases
    ├── 07_Identifier_Examples.js              # Complete valid & invalid JS identifier examples
    ├── 08_Comments.js                         # Single-line, multi-line, and JSDoc comments
    ├── VS_Code_keyboard_shortcut_mac.md       # VS Code keyboard shortcuts for macOS
    └── VS_Code_keyboard_shortcut_windows.md   # VS Code keyboard shortcuts for Windows
```

---

## 🚀 Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Visual Studio Code](https://code.visualstudio.com/)

---

## ▶️ How to Run the Examples

Clone the repository and run any JavaScript file using Node.js:

```bash
# Clone the repository
git clone https://github.com/Nand-Kumar/LearnPlaywrightBatch2x.git

# Navigate into the project directory
cd LearnPlaywrightBatch2x

# Run a specific file
node chapter_01_Basics/01_Basics.js
node Chapter_03_Identifier_Literals/07_Identifier_Examples.js
```

## 📖 Topics Covered So Far

1. **Chapter 01 - Basics**:
   - First JavaScript program, console execution, and hot code examples.
2. **Chapter 02 - JavaScript Concepts**:
   - Foundational JS concepts and variables.
3. **Chapter 03 - Identifiers, Literals & Comments**:
   - Complete JavaScript identifier rules and edge cases (Unicode, escape sequences, reserved words, strict mode).
   - Naming conventions (`camelCase`, `PascalCase`, `snake_case`, `SCREAMING_SNAKE_CASE`, `kebab-case`, etc.) and their use cases in JS & Playwright.
   - Single-line (`//`), multi-line (`/* ... */`), and JSDoc (`/** ... */`) comments.
   - Essential VS Code keyboard shortcuts for both **macOS** and **Windows**.
